P2P WebRTC Connection

Step 1: Host / Create Offer For Host

Generate an offer code and send it to your friend (via Discord, Slack, etc.).

Step 2: Join / Paste Offer & Create Answer For Guest

If your friend sent you an offer code, paste it below to generate your answer code.

Step 3: Finalize (Host Only) For Host

Paste the answer code sent back by your friend to complete the P2P connection.

Deploying to Vercel

This WebRTC Collaborative Animation Maker is 100% static and serverless. It requires no backend database or WebSocket server because it uses direct peer-to-peer WebRTC connections with copy/paste signaling codes!

Quick Vercel Deployment Steps:

  1. Save this file as index.html in a new folder.
  2. Initialize git and push your project to GitHub.
  3. Import your repository into Vercel.
  4. Leave build settings as default (static HTML) and click Deploy!

Tip: For best P2P connection success across different networks, public STUN servers (Google STUN) are pre-configured.
